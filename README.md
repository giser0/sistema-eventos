# Sistema de Reservas de Eventos

Aplicación web para la gestión y control de reservas de eventos.

## Tecnologías utilizadas
- Frontend: React
- Backend: NestJS (NodeJS)
- Base de datos: MySQL
- Autenticación con JWT
- CAPTCHA
- Docker

## Funcionalidades
- Registro y login de usuarios
- Roles: Administrador y Cliente
- CRUD de reservas con eliminación lógica
- Reportes en PDF
- Gráficos estadísticos
- Registro de logs de acceso
- Validación de contraseñas (débil, media, fuerte)
